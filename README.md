# SysitnOS

a small hobby OS

## Third-party components

SysitnOS relies on the following external projects:

- **[Limine](https://github.com/limine-bootloader/limine) (v11.x-binary)**: bootloader for the x86_64 and loongarch64 ports.
- **[libfdt](https://git.kernel.org/pub/scm/utils/dtc/dtc.git)**: used to parse the device tree blob (DTB) on the aarch64 and riscv64 ports.

Each component is distributed under its own license; see the respective projects for details.
